## Problem Solutions (50 Marks)

All solutions are implemented in [solutions.ts](solutions.ts):

| Problem | Function | Description |
|---------|----------|-------------|
| 1 | `filterEvenNumbers` | Filters array to return only even numbers |
| 2 | `reverseString` | Reverses a given string |
| 3 | `checkType` | Type guard to distinguish string vs number |
| 4 | `getProperty` | Generic function with key constraints |
| 5 | `toggleReadStatus` | Adds isRead property to Book objects |
| 6 | `Student` | Class extending Person with getDetails method |
| 7 | `getIntersection` | Returns common elements from two arrays |


## Blog Posts (10 Marks)

### Blog 1: Why `any` is a "Type Safety Hole" and Why `unknown` is the Safer Choice

This blog explains the critical difference between `any` and `unknown` types in TypeScript, demonstrating why `any` undermines type safety while `unknown` enforces proper type checking through type narrowing.

### Blog 2: How Generics Enable Reusable Type-Safe Components

This blog covers TypeScript generics, showing how to build reusable functions and classes that maintain full type safety across different data structures.
